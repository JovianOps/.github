## 🤝 Contribute (vibecoders welcome)

1. Read [`AGENTS.md`](https://github.com/JovianOps/bdd-steps/blob/main/AGENTS.md) — your agent is running in ~5 minutes (one server, one suite, all green).
2. Pick an issue labeled [`good first issue`](https://github.com/JovianOps/bdd-steps/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22) — Link and Metatag slices need no browser or Drupal.
3. Keep the suite green, update `README.md` / `STATUS.md` counts, open a PR. Fast review guaranteed.

Details: [`CONTRIBUTING.md`](https://github.com/JovianOps/bdd-steps/blob/main/CONTRIBUTING.md) · Truth about scope: [`STATUS.md`](https://github.com/JovianOps/bdd-steps/blob/main/STATUS.md)
